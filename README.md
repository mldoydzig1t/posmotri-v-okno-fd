# Посмотри в окно

Проектная работа спринта «Доступность и подходы к организации стилей»
курса «Фронтенд-разработчик» Яндекс Практикума.

Приложение показывает видеоролики с видами городов: слева — основной
плеер и форма поиска (город, время суток), справа — заголовок и список
карточек с превью. Логика на JavaScript была дана в заготовке, задача
проектной работы — оформить интерфейс по макету: раскладка на flex,
тексты, кастомные чекбоксы и поля формы, состояния `:hover`, `:active`
и `:focus-visible`, прелоадеры и кастомный скроллбар.

## Стек

- HTML — разметка из заготовки (не изменялась);
- CSS — `styles/style.css` (основная задача проекта), `styles/preloader.css`
  и `styles/error.css` — готовые компоненты из заготовки;
- JavaScript — `scripts/script.js` из заготовки.

## Запуск

Проект статический: откройте `index.html` в браузере или поднимите
локальный сервер:

```bash
python3 -m http.server 8000
```

## Особенности реализации

- раскладка на flexbox без абсолютного позиционирования
  (`.visually-hidden` — единственное исключение);
- отступы между элементами заданы через `gap`;
- псевдочекбоксы и их состояние `:checked` — на псевдоэлементах;
- обводка фокуса — через `outline`, для клавиатурной навигации
  используется `:focus-visible` (у полей формы обводится лейбл
  через `:has(:focus-visible)`);
- изображения и видео подогнаны через `object-fit` с `object-position`;
- заголовки карточек обрезаются многоточием, описания — через `line-clamp`.
